📊 DEPI Attendance Automation GUI - دليل البدء السريع
================================================

🚀 الخطوات الأولى:

1️⃣ اكتب الأمر التالي لتثبيت المكتبات:
   npm install

2️⃣ اكتب الأمر التالي لتشغيل التطبيق:
   npm start

3️⃣ سيظهر تطبيق جميل مع:
   ✅ حقول لاختيار التواريخ
   ✅ زر ابدأ وإيقاف
   ✅ عرض السجل الكامل

4️⃣ اختر التواريخ ثم اضغط "ابدأ العملية"

📋 ماذا يفعل التطبيق؟
- يسجل الدخول إلى DEPI Dashboard
- يحميل بيانات الحضور من خادم المؤسسة
- يصدّر البيانات إلى ملفات Excel و CSV
- يعرض التقدم في الوقت الفعلي

💡 نصائح مهمة:
- تأكد من أن الملف .env يحتوي على بيانات الدخول الصحيحة
- قد تستغرق العملية وقتًا (حسب عدد الجلسات والمجموعات)
- انتظر حتى تنتهي العملية تماما قبل الإغلاق

🎯 المخرجات:
- يتم حفظ الملفات في مجلد "exports"
- CSV files بيانات الحضور
- Excel files ملخص العمليات

محتاج مساعدة؟
- تحقق من GUI_README.md
- اقرأ رسائل الخطأ في السجل
- تأكد من اتصال الإنترنت
